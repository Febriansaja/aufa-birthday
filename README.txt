A LITTLE GIFT FOR AUFA
======================

CARA MENJALANKAN
1. Ekstrak folder aufa-birthday-website.
2. Buka folder tersebut di VS Code.
3. Klik kanan index.html lalu pilih Open with Live Server (jika Live Server terpasang), atau buka index.html langsung di browser.

GALERI FOTO AUFA
- Delapan foto yang kamu kirim sudah dimasukkan ke assets/photos.
- Foto langsung tampil untuk semua pengunjung website setelah folder di-hosting.
- Klik foto untuk melihatnya dalam ukuran lebih besar.

MUSIK BACKGROUND — ABOUT YOU (THE 1975)
- File musik yang kamu kirim sudah disertakan di assets/music/about-you.mp3.
- Musik mulai diputar saat pengunjung menekan tombol "Open your surprise".
- Tombol "About You · Play/Pause" di kanan atas bisa digunakan untuk mengontrol musik kapan saja.
- Musik diputar langsung dari website, tidak perlu membuka Spotify.
- Jika ingin mengganti lagu, ganti file assets/music/about-you.mp3 dengan file audio lain dan gunakan nama file yang sama.

CATATAN
- Website ini statis, tidak memerlukan database, PHP, atau instalasi framework.
- Foto yang dipilih melalui browser hanya tersedia di sesi browser tersebut; file tidak diunggah ke server. File musik disimpan lokal di folder assets/music sehingga ikut ter-host bersama website. Pastikan kamu memiliki hak atau izin untuk menggunakan dan membagikan file audio tersebut.
- Untuk mengirim ke Aufa, deploy folder ini ke hosting statis (misalnya GitHub Pages, Netlify, atau hosting web biasa). Jika ingin foto dan musik langsung tersedia bagi penerima, letakkan file media di folder assets dan ubah sumbernya di HTML/JavaScript.
- Efek font Google membutuhkan koneksi internet; font fallback tetap tersedia jika offline.
